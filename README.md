# Advancement Common Data Model (ACDM)

**An open, vendor-neutral data model for higher-education advancement.**

ACDM models the full advancement domain — constituents, gifts, designations,
planned giving, engagement (events, volunteers, memberships), stewardship and
scholarships, donor recognition, campaigns, marketing and communications, and
fundraising metrics — once, in the open, so your data stays yours and can move
between systems. It extends and aligns with the
[Microsoft Nonprofit Common Data Model (NCDM)](https://github.com/microsoft/Nonprofits)
and the
[CASE Global Reporting Standards](https://www.case.org/case-insights/case-global-reporting-standards)
rather than competing with them.

## Status: private beta

ACDM is currently in **private beta**. This repository will host the published
model as the beta opens up.

**→ To learn more, browse the model, or request beta access, visit
[fundcommons.org](https://fundcommons.org).**

## Open source

ACDM is an **open-source data model**, developed and stewarded by
**[Rigason LLC](http://rigason.com)**. It is built in the open as a commons for
the advancement community: one shared standard that institutions, vendors, and
consultants can all map to, instead of every CRM inventing its own schema.
